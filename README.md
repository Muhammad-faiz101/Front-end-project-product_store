# 🛍️ Faiz's Store – Frontend Project

Welcome to **Faiz's Store**, a simple front-end project built using **HTML, CSS, and a bit of vanilla logic**.  
This project demonstrates a responsive product store layout with filtering options and a clean UI.

---

## ✨ Features

- 🏷️ **Category Filters** – Users can filter products by Electronics, Clothing, Mobile & Tablets, and Furniture.  
- 📱 **Responsive Design** – Works smoothly on desktop, tablet, and mobile using CSS Grid + Flexbox.  
- 🔍 **Search Bar UI** – A placeholder search bar styled with hover effects.  
- 🖼️ **Product Grid** – Each product has an image, title, price, and "Add to Cart" button.  
- 🎨 **Modern Styling** – Uses shadows, rounded corners, and hover states for a neat look.
